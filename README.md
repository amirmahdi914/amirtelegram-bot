# بات تلگرام دستیار کسب‌وکار

این پروژه یه بات تلگرام شامل سه قابلیته:

1. **پاسخ خودکار بر اساس کلیدواژه** — جواب‌های ثابت که خودتون در `responses.py`
   تعریف می‌کنید (فعلاً به‌جای AI). هر وقت خواستید جواب هوشمند اضافه کنید،
   می‌شه یه ماژول AI جدا نوشت و در `bot.py` جایگزین `handle_message` کرد.
2. **گزارش روزانه‌ی قیمت** دلار، طلا (بازار ایران) و ارزهای دیجیتال برتر
3. **چک دوره‌ای سایت‌های کاریابی** برای پیدا کردن پروژه‌های جدید طراحی سایت

## نصب

```bash
pip install -r requirements.txt
```

## تنظیمات (متغیرهای محیطی)

| متغیر | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن بات از [@BotFather](https://t.me/BotFather) |
| `OWNER_CHAT_ID` | آیدی عددی شما برای دریافت گزارش‌ها (از [@userinfobot](https://t.me/userinfobot) بگیرید) |
| `JOB_CHECK_INTERVAL_HOURS` | فاصله‌ی چک پروژه‌ها به ساعت (پیش‌فرض: ۳) |
| `DAILY_PRICE_REPORT_HOUR` | ساعت ارسال گزارش روزانه قیمت (پیش‌فرض: ۹) |
| `JOB_KEYWORDS` | کلمات کلیدی جستجوی پروژه، با کاما جدا شده |

نمونه فایل `.env`:
```
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
OWNER_CHAT_ID=123456789
```

## ویرایش جواب‌های ثابت

برای تغییر یا اضافه کردن جواب‌های خودکار، فایل `responses.py` رو باز کنید
و دیکشنری `FIXED_RESPONSES` رو ویرایش کنید — هر کلید یه کلیدواژه‌ست و
مقدارش جوابیه که برای اون کلیدواژه فرستاده می‌شه.

## اجرا

```bash
python bot.py
```

## اجرای مداوم (۲۴/۷)

برای اینکه بات همیشه فعال باشه، باید جایی اجرا بشه که دائم روشنه. چند گزینه:

- **VPS ارزون** (مثل Hetzner، Vultr) + اجرا با `systemd` یا `screen`/`tmux`
- **Railway.app یا Render.com** — پلن رایگان دارن، فقط `requirements.txt` و `bot.py` رو push کنید
- **سرور شخصی** که همیشه روشنه (کمترین هزینه ولی نیاز به مدیریت داره)

## نکات مهم ⚠️

- **اسکرپینگ سایت‌های کاریابی**: قبل از فعال کردن این قابلیت روی هر سایتی،
  `robots.txt` و قوانین استفاده‌ی اون سایت رو چک کنید. `job_scraper.py`
  فقط یه نمونه‌ست و selectorهاش باید متناسب با ساختار واقعی صفحه تنظیم بشه
  (با Inspect Element در مرورگر).
- **قیمت طلا/دلار**: از HTML سایت tgju.org استخراج می‌شه چون API رسمی رایگان
  نداره. اگه نیاز به داده‌ی پایدارتر دارید، از یه سرویس API پولی مثل
  navasan.net استفاده کنید.
- **ارز دیجیتال**: فقط داده‌ی بازار (قیمت و تغییرات) نمایش داده می‌شه؛ بات
  هیچ توصیه‌ی سرمایه‌گذاری تولید نمی‌کنه چون این مسئولیت قانونی و اخلاقی داره.
- این بات **هیچ قابلیت ارسال خودکار پیام به گروه‌ها** (تبلیغات) نداره، چون
  چنین کاری با قوانین تلگرام در تضاده و می‌تونه منجر به مسدود شدن اکانت بشه.
